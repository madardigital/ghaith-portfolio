# Ghaith Portfolio

واجهة مستقلة ومختصرة لعرض نماذج أعمال غيث في تصميم وتنسيق الملفات، ومهيأة للزيارة من الهاتف وروابط TikTok.

## الأقسام الحالية
- تقارير التدريب وملفات الإنجاز
- مستندات ومشاريع احترافية
- العروض التقديمية
- تنسيق البحوث والتقارير الأكاديمية
- CV وفق نظام ATS
- آراء العملاء

سيتم توسيع المعرض لاحقًا بنماذج إضافية دون تغيير رابط المعرض الأساسي.
